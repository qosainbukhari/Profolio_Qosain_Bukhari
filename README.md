# Qosain Bukhari — Portfolio

Personal portfolio website of **Qosain Bukhari**, Junior Machine Learning Engineer (computer vision, RAG/LLMs, MLOps).

🔗 **Live site:** https://qosainbukhari.github.io/Profolio_Qosain_Bukhari/

## What's on the site

- Featured ML projects with problem, approach, results and pipeline diagrams
- Skills and tech stack
- Interactive "Architecture Lab" with ML system pipelines
- Education, experience and resume (view + PDF download)
- Contact form

## Built with

Plain HTML, CSS and JavaScript — no framework, hosted free on **GitHub Pages**.

```text
index.html   page content
style.css    styling
script.js    interactions and contact form
Resume.pdf   downloadable resume
Photo.jpeg   profile photo
```

## Run locally

```bash
git clone https://github.com/QosainBukhari/Profolio_Qosain_Bukhari.git
cd Profolio_Qosain_Bukhari
python -m http.server 8000   # open http://localhost:8000
```
