Fake News Detection

A modular NLP pipeline that cleans and vectorises news articles, compares four classifiers, tracks every run in MLflow and serves the best model through a FastAPI /predict endpoint, all reproducible with DVC.

01The problem

Misinformation spreads faster than people can fact-check it. A fast first-pass classifier can flag likely fake articles so human reviewers spend their time where it matters. The model has to be reproducible and easy to serve, not a one-off notebook.

02Data

The WELFake dataset: 72,134 articles (35,028 real, 37,106 fake) merged from Kaggle, McIntire, Reuters and BuzzFeed Political, with title, text and label columns, licensed CC BY 4.0.

03Approach

  1. Ingest. Read the raw CSV into a versioned artifacts folder, with paths in a config file rather than in code.
  2. Clean the text. Drop nulls, join title and text, lowercase, strip URLs, HTML and special characters, remove stopwords and lemmatise with NLTK, then make a stratified 80/20 split.
  3. Vectorise and train. TF-IDF with 5,000 features, then four classifiers compared on the same split.
  4. Track and reproduce. Every run's parameters and metrics go to MLflow; DVC defines the stages so dvc repro reruns only what changed.
  5. Serve. A FastAPI /predict endpoint with a small web UI, packaged with Docker and docker-compose.

06Limitations

  • The model learns the style of four source datasets and may not generalise to new outlets or topics.
  • Predictions aren't explained yet; per-word weights from Logistic Regression or LIME would help reviewers.
  • The split is random rather than by publication date, so it doesn't test performance on future news.
